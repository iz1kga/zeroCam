# Revisioni della meccanica

I file CAD sono binari: la differenza fra due commit non si legge. Questo file è l'unico posto dove è scritto **cosa** è cambiato e **perché**, quindi va aggiornato insieme ai file.

Ogni revisione pubblicata corrisponde a un tag git `hw-vX.Y`.

## Non ancora rilasciato

- Prima stesura della struttura: cartelle, distinta base e istruzioni da compilare.
