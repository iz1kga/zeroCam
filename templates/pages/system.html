Web interface access

HTTPS uses a certificate the device signs itself: the connection is encrypted, but the browser warns you the first time because nobody vouches for that certificate. The certificate covers localhost, the device name and its IP addresses on its own; here you add the other names you reach it by, for example the public one. The SHA-256 fingerprint to compare it against is written to the log at startup.
Turning HTTP off leaves HTTPS only: ONVIF stops working, because ONVIF clients only speak plain HTTP. Changes in this section take effect when the application restarts.

Public page

Exposes /public as a read-only shop window: latest shot, capture time and the live stream link if you give one. It needs no authentication and shows neither the configuration nor the log: it is the address to hand to people who only want to watch, instead of this console. Updates take effect immediately, without a restart.

Configuration backup and restore

[[ backupMessage ]]
Backup
The file holds the whole configuration (MQTT/FTP/ONVIF passwords, stream key, YouTube credentials) and the privacy mask, encrypted with this passphrase: without it the backup cannot be recovered, so keep it somewhere else. Left out are the web interface password and the session key, which stay those of the device you restore onto.
Restore
Overwrites the current configuration and the privacy mask: this cannot be undone. After a restore it is worth restarting the device from the Cam Control page.
