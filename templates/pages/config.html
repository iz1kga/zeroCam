FTP Upload

Uploads the freshly processed image to an FTP server after every shot, always overwriting the same file. Turning it off leaves the rest of the settings where they are.

HTTP Uploader

POST multipart/form-data to the endpoint with an Authorization: Bearer <token> header. The timestamp is generated in UTC at the moment of the shot.

Settings for the camera's automatic exposure in daylight conditions.

The gains only apply with AWB Mode set to Manual: automatic white balance is switched off and the balance stays fixed. This is the cure for sodium lighting, which AWB chases by tinting the whole image.

Settings for the manual bracketing algorithm in low-light conditions.

At night automatic AWB has no white to lock onto and sodium lighting leads it astray: with AWB Mode set to Manual the balance stays fixed on the gains you give. Good starting values can be read from the metadata of a shot that came out right, field ColourGains.

Creates the broadcast and binds it to the stream key above, with automatic start and no automatic stop: the stream comes up on its own and survives the pauses needed to take the photo, without opening a browser. Enter the Client ID and Client Secret of an OAuth client of type «TV and limited input devices» created in the Google Cloud Console, then press Authenticate to obtain the Refresh Token: there is no need to type it in by hand. In the title you can use the {date} and {time} placeholders. With «New broadcast at» filled in (e.g. 00:00) the running broadcast is closed and recreated at the first shot after that time; leave it empty and the same broadcast stays up for as long as YouTube keeps it.

Overlay Images

Logos

No logos. Add puts one in, then another: there is no maximum, but every enabled logo gets downloaded and drawn onto every single shot.

Logos can be dragged on the preview. Scale only shrinks: above 100% the logo stays at its own size, because enlarging a PNG blurs it. Opacity multiplies the transparency already in the file. Additions and removals only count after Save Configuration.

Annotation

The height of the bar is the font size plus twice the margin. The date format takes strftime codes: %d-%m-%Y %H:%M gives 03-08-2026 14:05.

Timelapse

Every shot leaves a resized copy in a folder of its own. Once a week the frames are built into a video and uploaded to YouTube with the credentials from the Stream section. The debug archive (Camera → Archive Images) is a different thing and is not used for this.
Frames
Frames are saved at the final video resolution already: building is faster and the disk footprint predictable. Raising the width increases disk usage in proportion.
Video
In the title and description you can use {from}, {to}, {date} and {frames}. Building runs at low priority so it does not disturb the stream: preset and threads set how much CPU it takes.
Audio
The track is looped until the frames run out and cut there. Files are uploaded on the Assets page. Mind the rights: a protected track can get the video claimed or blocked on YouTube.

Network
